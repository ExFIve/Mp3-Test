Overview
- Built a Spotify-like local MP3 web app (React + TypeScript + Vite).
- Users can import MP3 files from local machine, play tracks, browse songs/artists/albums, create playlists, and fetch internet metadata.

Implemented Features
- MP3 import:
  - File picker import.
  - Drag-and-drop import (including folder traversal where browser supports webkit entries).
- Metadata:
  - ID3 parsing via jsmediatags.
  - Duration extraction from audio metadata.
  - Online enrichment via iTunes Search API with localStorage cache/TTL.
- Playback:
  - Play/pause/seek/volume.
  - Next/previous + repeat modes.
  - Shuffle behavior fixed to use stable shuffled order (not random repeat on each next).
  - Previous-at-queue-start behavior fixed to set isPlaying=true consistently.
- Visuals:
  - Waveform visualizer added under the seek/progress marker in PlayerBar.
  - Progress marker line overlays waveform.
- Library and playlists:
  - IndexedDB (Dexie) for tracks and playlists.
  - Playlist create/rename/delete.
  - Add/remove/reorder playlist tracks.
